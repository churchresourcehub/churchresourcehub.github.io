Multi-Year Donor De-Identifier

Aligns every year of giving, plus membership info, to one stable code per household. Names never leave this page.

Runs entirely on your computer. No upload, no server, no internet call. You can turn off wi-fi and it still works. The only file you ever share is the coded dataset. Keep the key file private.
